## 2. Objective

The objective of this test plan is to define the testing approach, scope, resources, test scenarios, and acceptance criteria for the ShopEase demo e-commerce web application.

The project demonstrates practical manual testing skills including:

- Requirement analysis
- Test scenario identification
- Test case design
- Functional testing
- UI testing
- Positive testing
- Negative testing
- Boundary Value Analysis
- Input validation
- Cart and checkout testing
- Responsive testing
- Cross-browser testing
- Defect reporting
- Regression testing
- Test execution
- Test summary reporting

---

## 3. Scope

### 3.1 In Scope

The following application modules are covered:

- Login
- Product Listing
- Product Search
- Shopping Cart
- Cart Quantity
- Cart Calculation
- Checkout
- Navigation
- Responsive UI
- Cross-Browser Compatibility

### 3.2 Out of Scope

The following areas are not covered in this project:

- Backend API testing
- Database testing
- Performance testing
- Load testing
- Security penetration testing
- Payment gateway integration testing
- Real-world order fulfillment
- Production monitoring

---

## 4. Testing Approach

The following testing techniques were used:

| Testing Type | Description |
|---|---|
| Functional Testing | Verify application functionality against expected behavior |
| Positive Testing | Verify valid inputs and expected user actions |
| Negative Testing | Verify invalid inputs and error handling |
| Boundary Value Analysis | Test minimum, maximum and boundary values |
| Equivalence Partitioning | Divide input data into valid and invalid groups |
| UI Testing | Verify layout, controls and visual elements |
| Responsive Testing | Verify application on different screen sizes |
| Compatibility Testing | Verify application across different browsers |
| Regression Testing | Verify existing functionality after changes/fixes |
| Exploratory Testing | Identify unexpected issues outside planned scenarios |
