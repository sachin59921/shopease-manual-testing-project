## 📌 Project Overview

**ShopEase** is a demo e-commerce web application used as a testing project.

The objective of this project is to simulate a real-world QA testing workflow from **requirement analysis to final test summary**.

This project demonstrates how a Manual QA Engineer:

1. Analyzes application requirements
2. Identifies test scenarios
3. Designs detailed test cases
4. Executes test cases
5. Identifies and reports defects
6. Maps requirements with test cases
7. Prepares regression testing checklists
8. Generates a final test summary report

---

## 🎯 Project Objectives

The main objectives of this project are:

- Perform end-to-end manual testing.
- Validate core e-commerce functionality.
- Design structured and reusable test cases.
- Perform positive and negative testing.
- Validate input fields and boundary conditions.
- Identify and document defects.
- Maintain requirement-to-test-case traceability.
- Perform responsive and cross-browser testing.
- Prepare professional QA documentation.

# 🧪 Testing Scope

The following modules were tested:

| Module | Coverage |
|---|---|
| 🔐 Login | Valid/Invalid Login |
| 📝 Login Validation | Required fields & input validation |
| 🛍️ Product Listing | Product details & prices |
| 🔎 Product Search | Exact, partial & invalid searches |
| 🛒 Shopping Cart | Add, update & quantity validation |
| 🧮 Cart Calculation | Quantity and total calculation |
| 💳 Checkout | Empty and valid cart checkout |
| 🧭 Navigation | Home, Products & Login |
| 📱 Responsive UI | Mobile viewport testing |
| 🌐 Browser Compatibility | Chrome, Edge & Firefox |
